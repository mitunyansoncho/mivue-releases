# MIvue

EViews 互換の計量経済ソフトウェア **MIvue** の配布ページです。このリポジトリは配布専用で、ソースコードは含まれていません。

English version: [README.en.md](README.en.md)

## ダウンロード

最新の ZIP は [Releases](https://github.com/takesue-mitsunao/mivue-releases/releases) から取得してください。

- `MIvue-0.3.0-windows-x64.zip`（GUI 版、Windows 10/11、64bit）
- `MIvue-cli-0.3.0-windows-x64.zip`（コマンドライン版、Windows 10/11、64bit）

GUI 版は ZIP を展開し、`MIvue\MIvue.exe` を起動します。インストールは不要です。
コマンドライン版は、AI エージェントにセットアップさせることができます。手順は [AGENT_SETUP.md](AGENT_SETUP.md) をエージェントに読ませてください。コマンドの書式は [COMMAND_REFERENCE.md](COMMAND_REFERENCE.md) にまとめています。

## 初回起動と SmartScreen

署名のない実行ファイルのため、初回起動時に Windows SmartScreen の警告が出ることがあります。その場合は「詳細情報」→「実行」を選んでください。

## 使い方の要点

- ワークファイル（.evwf）の中に系列・方程式・グラフなどのオブジェクトを作成します。作業フォルダは、前回の場所が自動で復元されます。
- EViews 風のコマンド（`wfcreate` / `series` / `equation ....ls` / `graph` / `wfsave` など）で操作でき、推定ダイアログからコマンドなしでも推定できます。
- 0.3.0 から、GUI を開いているセッションへコマンドライン版（`mivue --live`）が接続できるようになりました。エージェントが開いているワークファイルへ直接コマンドを実行でき、変更は画面へ反映され、操作は記録に残って取り消せます。
- はじめて使う方は [かんたんマニュアル](MANUAL.md) を参照してください。詳しい操作は、配布 ZIP 内の `README_DIST.md` にも記載があります。

## 利用について

- 学生・研究者への無償配布を目的としています。
- EViews は IHS Global Inc. の商標です。本ソフトは EViews の提供元とは関係のない独立した実装であり、「互換」は、同じ入力を与えたとき、明示した数値許容差の範囲で同じ結果を返すことを指します（検証報告書の定義によります）。

## 検証について

- 検証は版 0.1.0 を対象に実施しました。0.2.0 と 0.3.0 は、数値・コマンド文法・保存形式を変更していません（各版のリリースノートに記載しています）。
- 検証済みの範囲: 線形回帰と診断統計、単位根・共和分、操作変数法と GMM、ARCH 族、離散選択と GLM、パネル推定とパネル単位根・共和分、VAR とシステム推計、状態空間、ファイル形式（.wf1 の読み書き、.edb の読み取り）など。根拠は、公表された数表・印字例との全セル照合、公式文書の式からの独立再計算、全体テスト、および独立した監査によるブラックボックス照合の4種です。
- 限界: 公表値の裏付けがない領域は独立再計算を根拠とし、実機の EViews との照合はスポット照合が中心です。乱数列は EViews と一致しません。参照仕様は EViews 12 が中心です。範囲と限界の詳細は検証報告書を参照してください。

## 開発について

本ソフトは、著者が仕様を固定し、判断と受入の判定を行い、実装と検証の作業は AI エージェントが行う方法で開発しました。検証の期待値は、公表された数表と公式文書の式を出所としています。独立監査で見つかった不一致 6 件の扱い（再現・修正・再検証）や、参照資料どうしが食い違う場合の裁定は、著者が判定しました。監査は、実装を担当した AI と文脈を共有しない別の AI が、実装コードを見ないブラックボックスの形で行いました。

## 数表と出典

p 値・臨界値の計算には、次の公表資料の数値を使用しています（出典はプログラム内にも記録されています）。

- MacKinnon (1996)、MacKinnon–Haug–Michelis (1999): 単位根・共和分検定の応答曲面。配布については著者 James G. MacKinnon の同意を得ています（学生・研究者への無償配布）。
- Levin–Lin–Chu (2002)、Im–Pesaran–Shin (2003)、Pedroni (1999, 2004)、Pesaran (2007): パネル検定の調整項・臨界値。
